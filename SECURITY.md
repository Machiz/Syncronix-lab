# Seguridad

WireWatch MCU es una herramienta educativa y de diagnóstico de baja tensión.

- No la conecte directamente a tensión de red.
- No aplique 5 V a entradas que solo admiten 3.3 V.
- Use divisores, adaptación de nivel, aislamiento y protección cuando corresponda.
- Verifique las hojas de datos antes de energizar un componente.
- Trate los resúmenes descargados de internet como información no verificada.

Para reportar una vulnerabilidad, abra un aviso privado de seguridad en GitHub
en lugar de publicar inmediatamente los detalles explotables.
